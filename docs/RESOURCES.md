# External Resources

Reference links for filling in missing jurisdiction, office, and district data. Informational only — not scraped or scripted against automatically.

- **[The Green Papers](https://www.thegreenpapers.com/)** — election dates, candidate filings, and party/primary details useful for verifying office terms and election cycles.
- **[Nested Divisions (Google Sheet)](https://docs.google.com/spreadsheets/d/139NETp-iofSoHtl_-IdSSph6xf_ePFVtR8l6KWYadSI/edit?gid=472838709#gid=472838709)** — authoritative national geography lookup and source-to-canonical mapping audit built on TIGER/Line 2025, covering all nested state/county/place divisions. Useful for cross-checking GEOIDs and jurisdiction names/boundaries.
- **[Census TIGERweb](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/tigerWMS_Census2020/MapServer)** — Census Bureau's TIGER geography map service, useful for looking up district and jurisdiction boundaries directly.
