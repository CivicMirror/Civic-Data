How the schemas fit together

Seven files in schemas/ describe every record in this repo. The spine runs left to right: a geographic Division is governed by a Jurisdiction, which contains Organizations, which define Posts. A Membership is what puts a Person in a Post for a stretch of time, and an Election records the event that seated them. Click any box to read its fields and see a real record — one thread of Massachusetts data, Michelle Wu's Boston mayoralty, followed end to end.
